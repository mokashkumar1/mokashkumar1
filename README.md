## About

I'm a **Computer Systems Engineering** student at Mehran University of Engineering and Technology (MUET), focused on software development and applied AI. I enjoy turning real problems into useful products—from academic platforms and workflow tools to structured LLM applications and Windows utilities.

My current interests include **backend development, full-stack applications, machine learning, LLM-powered products, performance benchmarking, and practical automation**.
